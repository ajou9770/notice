🔍 쿠폰 등록 및 사용방법

✨ 빠른 Tip
  • 카톡 메시지 상단의 쿠폰번호(영문+숫자 10자리)를 먼저 메모해 주세요.
  • 이미지가 잘 안 보이면, 이미지를 터치해서 확대해 보세요.
  • 쿠폰 적용은 결제 단계에서 선택하면 자동 할인됩니다.
1
🎫 쿠폰번호 확인
카톡 메시지 상단의 쿠폰번호(영문+숫자 10자리)를 확인하고 메모하세요.
2
📲 쿠폰등록&사용하기 버튼 클릭
카톡 메시지 하단의 “쿠폰등록&사용하기” 버튼을 눌러 이동합니다.
3
🔐 회원가입 또는 카카오 로그인
간단 회원가입 또는 카카오계정으로 로그인 후 진행하세요.
4
🧾 마이쇼핑 → 쿠폰 메뉴 이동
마이쇼핑 > 쿠폰에서 쿠폰인증번호 등록을 선택합니다.
5
✅ 쿠폰번호 입력 후 인증
쿠폰번호 10자리 입력 → 쿠폰번호인증 버튼 클릭
6
🎉 등록 완료 메시지 확인
등록이 정상 완료되면 안내 메시지가 표시됩니다.
7
🛍️ 상품 구매 후 쿠폰 적용
특판 상품 구매 시 쿠폰을 적용하고, 차액이 있으면 결제합니다.
8
🏷️ 쿠폰 선택 → 할인 적용
쿠폰 선택 시 액면가만큼 자동 할인됩니다.
